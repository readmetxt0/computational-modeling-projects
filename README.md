# computational-modeling-projects
C++ projects for computational modeling and numerical simulation with mathematical explanations.

## Практические занятия по проектированию интеллектуальных систем (вариант 10, Python)

Каждая папка самодостаточна: код нарастает от занятия к занятию, отчёт собирается `python make_report.py`, интерфейс запускается `python gui.py`.

| Папка | Тема | Отчёт |
|---|---|---|
| `pz1/` | Входная обучающая матрица Y | `PZ1_otchet.docx` |
| `pz2/` | Бинарная обучающая матрица X | `PZ2_otchet.docx` |
| `pz3/` | Эталонные векторы EV | `PZ3_otchet.docx` |
| `pz4/` | Кодовые расстояния SK, SK_PARA | `PZ4_otchet.docx` |

Зависимости: `numpy pillow matplotlib python-docx`.
